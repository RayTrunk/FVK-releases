# FVK Releases

Distribution-only releases for Faro Virtual Keyboard (FVK). No source code here — see the private `FVK` repository for that.

Each release's tag is the version number (e.g. `v1.0.1`) with the corresponding `FVK.msi` attached as an asset. The app's built-in auto-updater checks this repo's latest release via the public GitHub API.
